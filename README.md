# 🚆 IRCTC CLI Booking System

A simple Java-based Command Line Interface (CLI) application inspired by the IRCTC ticket booking system. The project was built to practice Core Java concepts, object-oriented programming, and Gradle project management.

---

## 🚀 Features

- ✅ User Registration
- ✅ User Login
- ✅ Ticket Booking
- ✅ View Booking Details
- ✅ Command Line Interface (CLI)
- ✅ Gradle Build Support

---

## 🛠️ Tech Stack

- Java
- Gradle
- Core Java
- Object-Oriented Programming (OOP)

---

```
app/

```

## ▶️ Running the Project

Clone the repository

```bash
git clone https://github.com/MLwithvaibhav/IRCTC.git
```

Run using Gradle

```bash
./gradlew run
```

(Windows)

```bash
gradlew.bat run
```
